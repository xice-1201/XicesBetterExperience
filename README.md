# Xice的体验优化

适用于 **Probably Stolen** 的体验优化模组，改善日常经营中的重复操作与物品信息展示。各项功能可在游戏内独立配置。

[使用与配置](#使用与配置) · [从源码构建](#从源码构建) · [问题反馈](https://github.com/xice-1201/XicesBetterExperience/issues)

## 兼容性

| 项目 | 说明 |
| --- | --- |
| 当前模组版本 | 0.5.4 |
| 支持的游戏内部版本 | `0.46D` |
| 加载方式 | 游戏内置 Mod 系统 |
| 界面语言 | 简体中文、英文 |
| Mod ID | `xice.betterexperience` |

模组会检查游戏内部版本字符串。游戏更新后，请确认兼容性再安装对应版本。

## 安装

将构建好的 `XicesBetterExperience` 文件夹放入游戏安装目录下的 `Mods` 文件夹，目录结构应为：

```text
Probably Stolen/
└── Mods/
    └── XicesBetterExperience/
        ├── manifest.xml
        ├── XicesBetterExperience.dll
        └── Localization/
            ├── zh.csv
            └── en.csv
```

启动游戏，在 Mod 菜单中启用 **Xice的体验优化**，随后重启游戏完成加载。

更新时请先退出游戏，再用新版本覆盖同名文件夹。禁用模组可通过游戏内 Mod 菜单完成；卸载时，退出游戏后移除该文件夹。

本仓库提供源码。GitHub 的源码压缩包不包含可直接加载的 DLL，请按下文构建后安装。

## 使用与配置

在游戏的 Mod 菜单中打开本模组的配置界面。设置按用途分为三个标签页：

| 标签页 | 用途 |
| --- | --- |
| 通常 | 调整指南开关、文档阅读和日常经营中的辅助操作 |
| 图标 | 调整物品名称、状态标记及告警信息的展示 |
| 自动化 | 调整鉴定自动化与免疫宁注射器检查辅助 |

各配置项的具体说明可通过旁边的信息提示查看。修改后点击 **应用**；点击 **重置** 可恢复界面中的默认值，再应用保存。设置由游戏原生配置系统保存，跨存档共用。

勾选项默认开启。自动化标签页中的功能默认均为 **不开启**。机械手可选初级至专家，肋明治可选中级至专家，等离子燃料匣可选高级或专家。滑动条仅显示当前选择；已保存的机械手设置继续保留，重置后恢复不开启。

### 使用说明

- “随心所欲”专长位于新游戏专长列表首位，默认仍选中学徒。选中后，“初始拥有”区域按“基础／物资／人脉／事件”分页，标签栏固定，每页配置区支持鼠标滚轮及右侧滚动条；切换标签保留已编辑的设置。可通过滑动条或输入框设置0～10000初始资金，默认600；物资页的“初始储藏区”默认不勾选，勾选后获得一个破旧储藏区，不额外扣款。“初始食物”和“初始日用品”也默认不勾选：分别提供代糖果汁×1与“泥炭”合成肉×2，以及一支牙膏×2与一卷厕纸×2。“强制跳过开局”会锁定难度页的跳过开局选项；“禁用开局物资补发”会取消手动或强制跳过开局带来的额外物资，但保留教程状态解锁及自行选择的初始物品，两项默认均不勾选。“初始水资源处理工具”提供原版水商开局物资，保留水质、设备耐久和预装电池，不额外扣款；“初始水贩人脉”独立解锁水资源交易，退休水商在第3、10、17……天来访，食品换物教学改为交换一盒净水片。两项默认不勾选；跳过开局时水商灯牌也受禁用补发选项控制。“初始暗格”“初始违禁品”“初始暗灯”独立提供销赃者对应物资；“初始清道夫地下交易所权限”立即解锁地下交易，并在首日首位顾客处使用销赃者版本介绍，后续不再触发普通地下交易介绍。这四项默认不勾选，不附加销赃者的扣款、租金或声望变化。人脉页可设置五类初始声望（-200～200，默认0），非零值通过原版声望调整接口处理并受到原版倍率影响；物资页的“初始音乐磁带”默认不勾选，关闭时不发通常的四盒开局磁带，开启时仍遵循原版特质限制。基础页的“初始房租”位于资金项之后，可用滑条或输入框设置首周租金（10～2000，默认200），后续租金按原版规则上涨。事件页的“王尔德的救济”可用滑条或输入框设置每局最大触发次数（0～10，默认0），每次至少相隔10天，保留原版经营困难及难度条件；次数上限、已用次数和上次触发日期随存档保存，上限非零时开放升级浏览及电话联络提醒。物资页还可独立勾选水培、养鼠、水产养殖及化学设备，按原版对应专长配给生成，保留预装模块、水电、耗材及生物的年龄和性别；不附带其人脉、服务、声望、资金或租金变化。人脉页可独立解锁退休农夫、养殖、水产养殖、退休化学家、退休枪匠及I级武器许可；每周顾客沿用原版日程，化学家人脉包含可疑农夫和黑市交易商，I级许可还安排第1、4天的枪械买家与第2天的枪械卖家。许可按原版方式放置并激活，六项默认不勾选。其余条件使用原版通用开局。最终资金在特质效果之后、首次存档之前应用，设置会记住供后续开局使用。
- 禁用展示柜提示默认开启，拦截所有专长下关于展示柜生效时机的提示弹窗。
- 自动续订为四个供货商的通讯录条目增加“自动／停止”按钮。启用后按上次手动选择的档位订货，无记录时优先大额订单；尚未解锁时使用普通订单。大额订单新解锁或供货商拒绝服务时自动停止。各供货商的启用状态和手动订单偏好随当前游戏存档保存；总配置关闭时暂停，重新开启后恢复并检查资格。
- 一包海明威香烟检查自动化默认关闭，可按持有指南、色卡条件启用；自动选择有效理由或禁用错误理由，质疑与解释仍由玩家手动执行。自动打开和关闭鉴定指南也支持海明威指南及色卡。
- 自动鉴别改造体默认关闭，仅在改造体危机进行期间生效。外观线索在进店时识别，动作线索在站定后识别，语言线索在对应异常台词显示时识别；成功后以红色轮廓高亮霰弹枪，开枪仍由玩家手动操作。

- 保留子窗口布局支持平板电脑、电话、档案箱、垃圾桶、水质扫描仪、自动售水机、自动售货机，以及物品检查／鉴定窗口（含鉴价盘面）、多页指南、香烟指南与色卡、邮票指南、注射器指南和植入物指南。各窗口独立保存位置，可缩放的平板和指南同时保存缩放档位；多页指南按书籍分别记录。布局跨存档及游戏重启生效，分辨率变化时换算位置并保证标题区域可见。拖动或缩放完成后保存，关闭该功能时保留已有记录。
- 自动清理回执会将鉴定单、市场情报、普通传闻纸条，以及治安部盘查没收后生成的检查回执自动放入垃圾桶。
- 夜间服务信息在睡觉前显示警报系统的有效防盗率、清洁服务可能清走杂物的提醒；持有治安部档案时，还会显示涉案金额和调查进度，并以颜色提示善后人能否消除风险。
- 电量告警也会显示在店铺场景中的自动贩卖机和售水机上。
- 溢出告警支持水分收集器容量不足、净水器达到当前品质加成下的纯度上限，以及蒸发器预计回收量大于零且缺少收获容器或其容量不足。蒸发器预估考虑原料、性能、品质和溶剂回收模块；电量告警优先显示，状态变化时刷新。
- 储藏区命名与容量比例也支持玩家拥有的冰箱；冰箱容量合计冷藏区和冷冻区。
- 储存区容量比例合计各储藏分页的已占用格数与可用格数，显示两位小数；不超过 30% 为绿色，达到 70% 为红色，其余为黄色。

- 免疫宁注射器检查自动化可按持有检测指南或始终启用，自动选择一个正确的质疑理由；确实为正品时禁用问题理由。质疑仍由玩家手动提交，离开检查后恢复控件。原版未提供的正品解释流程保持不变。检测指南也支持自动打开和关闭。
- 鉴定自动化需要满足对应证书和原版服务条件，未满足时保留手动鉴定流程。
- 市场箭头反映物品所有类型的当前市场变动之和；上涨显示红色上箭头，下跌显示绿色下箭头，相互抵消时隐藏。水、食品、医疗、日用品、材料和两种枪械霓虹灯牌会显示对应商品类型的市场变化；两种枪械灯牌及三级枪械许可均合计武器与枪械两类变动。
- 文档翻页记忆保留在当前游戏进程中，退出游戏后重置。

## 从源码构建

### 环境要求

- Windows 与 PowerShell。
- 已安装的 Probably Stolen，包含 `Probably Stolen_Data/Managed` 下的游戏程序集。
- Unity Editor `2022.3.61f1c1`，构建脚本使用其中的 .NET 运行时和 Roslyn 编译器。

在仓库根目录执行，并将路径替换为本机安装位置：

```powershell
.\build.ps1 `
    -GamePath 'D:\SteamLibrary\steamapps\common\Probably Stolen' `
    -UnityEditorPath 'D:\Unity\2022.3.61f1c1\Editor'
```

构建产物位于 `dist/XicesBetterExperience/`，需手动复制到游戏的 `Mods` 目录。游戏程序集仅作为编译引用，不随模组分发。

### 验证

运行回归测试：

```powershell
.\tests\Run-Regression.ps1 `
    -UnityEditorPath 'D:\Unity\2022.3.61f1c1\Editor'
```

回归测试使用游戏接口替身检查配置与功能逻辑；构建使用实际游戏程序集校验 API。涉及界面布局、Harmony 加载和存档交互的改动，还需要在游戏内验证。

### 目录结构

```text
src/            模组实现与界面补丁
Localization/   配置界面的本地化文本
tests/          回归测试与运行脚本
manifest.xml    模组清单与兼容性声明
build.ps1       构建脚本
```
