# Xice的体验优化

为 **Probably Stolen** 制作的独立体验优化 Mod，参考 Xice的流体管道的项目结构。

当前版本：**0.3.8**，提供鉴定自动化、鉴定指南自动开关、储藏区图标名称显示、保留文档翻页、赃物及违禁品标记、电量告警、市场变动显示、单格价值、地下交易自动提货、鉴定回执自动清理，各功能可独立配置。

## 功能与配置

### 单格价值

默认开启。在原版价值信息中显示单格价值，计算方式为物品自身预估价值除以当前旋转方向实际占用的格数，数值显示在预估价值和基础价值之间。容器内子物品的价值不计入自身预估价值。配置键为 `single_cell_value`。

### 赃物标记

默认开启。仍有正赃物热度的物品图标显示黄色边框，热度归零或原版移除赃物状态后自动消失；普通物品和已冷却赃物不显示。标记覆盖普通图标及拖动预览，不拦截鼠标操作。配置键为 `stolen_marker`，关闭后立即隐藏标记。

### 违禁品标记

默认开启。带有原版违禁品等级的物品图标显示红色边框，覆盖普通图标及拖动预览；违禁品状态移除后自动隐藏。与黄色赃物标记可同时显示，分别使用独立配置 `contraband_marker` 和 `stolen_marker`。

### 市场变动显示

默认开启。将物品所有类型的原版市场价值变动百分比相加：合计为正时在物品当前占用区域左上角显示红色上箭头，为负时显示绿色下箭头，为零时隐藏图标。因此同时受相反方向事件影响的多类型物品会按净变动显示。箭头边长为半个单元格，配置键为 `market_change_marker`。

### 鉴定自动化

五档整数滑动条从左到右为 **不开启、初级、中级、高级、专家**，默认在 **专家**。
界面显示完整档位顺序和当前所选档位，重置设置时恢复专家。
配置键为 `appraisal_automation`，数值 0 至 4；修改后点击原版“应用”按钮生效。

达到所选鉴定师等级，且当前拥有相应或更高级的有效证书后，对顾客委托的物品开始鉴定时，
直接提交原版真实估值，判定为完美鉴定。证书依次为 `cert1`、`cert2`、`cert3`、`cert4`。
由于原版晋级会销毁旧证书并发放高级证书，高级证书继续满足较低档位的要求。
已有存档同样适用，无需重新获得证书；不要求证书摆在展示柜中。

不弹出鉴定界面或自动打开指南，仍保留原版完美鉴定结果对话、报酬、凭条、晋级进度、
成就及顾客离场流程。只对原版鉴定服务顾客的非自有 `APPRAISAL_ITEM` 生效，
不消耗玩家自己的物品，不影响交易顾客或普通检查。
证书未满足条件、已丢失/卖出/销毁、未加入鉴定协会、关闭功能或无法取得有效估值时走手动流程。
顾客已失去耐心等原版限制仍由原版结算处理。

实现为 `InspectionUIManager.OnInspectItem` 前置检查，成功时调用
`AppraisalServiceHelper.OnEstimate(item, AppraisalHelper.GetCorrectBaseValue(item))` 并跳过原方法；
自动打开指南的后置补丁检查 `__runOriginal`，避免对已自动结算的物品再打开指南。
自动化不自行发钱或修改成就。结算一旦开始后出现异常，不再回退重试，以避免重复副作用。
回归覆盖五档与四种证书/无证书的25种组合、所有权及身份限制、真实估值委托、
销毁目标不重复处理、错误隔离、五档文字和重置刷新；实际 Unity 界面与结算仍需游戏内验证。

### 鉴定指南自动开关

开始鉴定机械手、肋明治或燃料罐时，如果当前拥有对应的鉴定指南，自动打开原版指南界面。
查找范围沿用原版自有物品遍历，包括文档栏、嵌套容器及隐藏库存；不要求指南所在的库存窗口可见。
不拥有指南、指南已销毁或当前无法阅读时不打开。其他物品的鉴定不受影响。
对应指南已经打开时保留当前页码；打开另一种指南时沿用原版从第一页开始的行为。
完成鉴定或手动关闭鉴定窗口时，自动关闭对应指南，沿用原版关闭音效。
若指南已关闭则不重复关闭；若已切换到其他文档则保留其他文档。
鉴定前手动打开的对应指南也会随鉴定结束关闭。

在游戏 Mod 列表中打开本 Mod 的设置，修改“自动打开和关闭鉴定指南”并点击“应用”。
该设置默认开启，由游戏原生配置系统保存，跨存档共用，沿用 0.1.0 的配置键及已有选择。
关闭设置或禁用 Mod 后停止自动打开及关闭；
已经打开的指南保留，仍可按原版方式手动打开或关闭。
设置名称及提示提供中英文，其他语言沿用原版英文回退。

### 储藏区命名

默认开启。在储藏区、机器储藏区、化学家储藏区、走私者暗格及其扩建形态的图标底部，
显示蓝色标签打印机设置的自定义名称；也涵盖简易储藏区和迷你暗格。
适用物品 ID：`makeshift_storage_bay`、`storage_bay`、`storage_bay_large`、
`storage_bay_gun`、`storage_bay_chem`、`smuggler_bay_mini`、`smuggler_bay`、`smuggler_bay_mod`。
储藏区扩建套件增加标签页但不改变物品 ID，因此扩建后继续显示名称；外观切换同样保留。

未命名或名称仅含空白时不显示。重命名、清除名称和读档时自动更新，拖动预览也显示名称。
文字采用原版当前语言字体、白字黑色阴影；在图标范围内自动缩小、换行，过长时省略。
文本按原文显示，不解析富文本标签，不拦截鼠标，不替换原版堆叠数量或其他图标覆盖层。
关闭“储藏区命名”并应用后立即移除显示，重新开启则恢复；原版保存的名称始终保留。

### 地下交易自动提货

默认开启。前一晚完成的地下交易收获会在第二天早晨放入前台柜台；若柜台空间不足，则依次尝试后柜台、玩家背包、展示柜，最后才放入垃圾桶。投递等待早晨店铺界面完成初始化，并重置外出地点遗留的柜台坐标，避免货物出现在店外。设置项为“地下交易自动提货”。

初次启用 Mod 后需要重启游戏，原版才会加载程序集并提供配置按钮。

### 自动清理回执

默认开启。鉴定机械手、肋明治或燃料罐时生成的鉴定单，以及市场情报和普通事件传闻纸条，会通过原版投放接口自动放入垃圾桶；其他鉴定物品的回执不受影响。设置项为“自动清理回执”。

## 项目信息

### 保留文档翻页

默认开启。修复原版多页指南每次打开都重置到第一页的问题。
每种指南独立记住最后阅读的页面，关闭重开、直接切换文档及鉴定指南自动开关均适用。
恢复页面时同步更新页码文字及左右翻页按钮；页数缩减时自动限制到最后一页。
适用于原版 `MultiPageUIManager` 管理的全部多页指南，不限于三种鉴定指南。
普通书籍沿用原版已有的物品页码保存逻辑。

记忆在本次游戏进程中保留，不写入存档或配置文件，退出游戏后重置。
关闭“保留文档翻页”时，原版多页指南恢复从第一页打开，且暂停记录页码；
重新开启后可继续使用关闭功能前的记忆。现有两个设置保持独立。

- Mod ID：`xice.betterexperience`
- 程序集及命名空间：`XicesBetterExperience`
- 兼容游戏版本：`0.46D`，入口严格检查版本字符串。
- 独立加载，不依赖流体管道 Mod。

## 构建

```powershell
.\build.ps1 -GamePath 'E:\Steam\steamapps\common\Probably Stolen'
```

沿用流体管道项目的 Unity Editor Roslyn 编译工具链，默认 Editor 路径为
`E:\UnityHub\UnityEditor\2022.3.61f1c1\Editor`，可通过 `-UnityEditorPath` 覆盖。
输出位于 `dist/XicesBetterExperience/`，不会自动部署到游戏。
游戏程序集只作为编译引用，不随 Mod 打包。

## 安装

将构建生成的 `XicesBetterExperience` 文件夹复制到游戏的 `Mods` 目录，然后在游戏中启用。

## 实现与验证

游戏 ModLoader 自动加载 Harmony 补丁。在 `InspectionUIManager.OnInspectItem(GameItem)`
后置回调中查找自有指南，再调用与原版指南激活回调相同的 `MultiPageUIManager.OpenUI`。
机械手、肋明治、燃料罐分别使用 `hand_guide` / 6、`ribwich_guide` / 4、`fuel_guide` / 0，
与 0.46D 的 `MiscItemDirectory` 原生指南工厂对应。补丁检查 `ModEntry.IsEnabled` 及当前配置。
每次鉴定重新检查所有权，不缓存指南引用，不修改物品或存档。
在 `InspectionUIManager.CloseUI()` 前置回调中记录当前鉴定物品对应的指南索引，
避免原版清空 `currentInspectingItem` 后丢失上下文；后置回调仅在对应指南仍打开时
调用原版 `MultiPageUIManager.CloseUI()`。提交鉴定估价和手动关闭都经过此入口。

运行 `.\tests\Run-Regression.ps1` 检查生产代码的配置注册、三类指南映射、所有权、
已销毁物品、关闭开关/禁用、阅读限制、已打开页码保留、结束鉴定关闭对应指南、
其他文档隔离、重复关闭及异常隔离。
测试使用原生接口替身；真实游戏程序集构建验证 API 签名。
游戏内 Harmony 加载、窗口布局、配置持久化及读档后的实际行为仍需游戏内验证。

储藏区显示使用独立的原版 `TreeNodeRender` 文字节点，分别挂接到 `middle` 与 `fakeMiddle`，
跟随正常物品和拖动预览的层级。读取 `GeneralHelper.GetCustomName`，不写入物品字段或新增存档数据。
补丁覆盖图标验证、原版命名/清除、普通图标和拖动预览显隐及物品销毁。
启用、晚期读档、配置应用时刷新已有库存；禁用时销毁本 Mod 创建的节点并解除事件。
回归测试覆盖八种 ID、扩建状态、命名/清除、长文本边界、鼠标与富文本隔离、
普通/拖动显隐、独立配置、读档及生命周期清理。文字实际布局和蓝色打印机交互需游戏内确认。
